# OIBSIP – Web Development & Designing Internship

A collection of web development projects completed as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2**. This repository showcases hands-on implementation of interactive web applications, frontend development, application logic, backend fundamentals, and authentication workflows.

## Projects

### 1. Calculator
An interactive calculator application featuring arithmetic operations, expression handling, keyboard interactions, and error handling.

- **Technologies:** HTML, CSS, JavaScript
- **Focus:** Expression parsing, event handling, DOM manipulation, interactive UI, and responsive design.

[View Calculator Project](./WebDev-L2-Calculator/)

---

### 2. Tribute Page – B. J. Habibie
A responsive tribute website dedicated to B. J. Habibie, presenting his biography, achievements, contributions, and legacy through structured content and visual storytelling.

- **Technologies:** HTML, CSS
- **Focus:** Responsive layout, structured content presentation, visual hierarchy, and web design fundamentals.

[View Tribute Page Project](./WebDev-L2-TributePage/)

---

### 3. Daylist – To-Do Application
An interactive task management application designed to organize daily activities, track task completion, and monitor productivity.

- **Technologies:** HTML, CSS, JavaScript
- **Focus:** CRUD operations, dynamic DOM manipulation, task filtering, progress tracking, and Local Storage persistence.

[View Daylist Project](./WebDev-L2-ToDoApp/)

---

### 4. Northstar – Login & Authentication
A web application exploring authentication workflows through user registration, login validation, password security, and session-based access handling.

- **Technologies:** HTML, CSS, JavaScript, Node.js, Express.js
- **Focus:** Server-side routing, authentication workflows, password hashing with bcryptjs, session management, and backend fundamentals.

[View Northstar Project](./WebDev-L2-LoginAuthentication/)

---
